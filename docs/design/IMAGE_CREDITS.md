## Criterios

- No se incorporan imágenes encontradas mediante búsquedas genéricas sin comprobar la página original y su licencia.
- Las fotografías de jugadores solo se incorporarán desde una fuente que identifique la licencia del archivo individual, por ejemplo Wikimedia Commons.
- Tennis Abstract puede utilizarse como fuente de datos y enlace de referencia, pero sus fotografías no se copiarán mientras no exista una autorización pública y verificable para reutilizarlas.
- Las imágenes decorativas no reemplazan información y deben llevar texto alternativo vacío. Las imágenes informativas deben incluir texto alternativo útil.
